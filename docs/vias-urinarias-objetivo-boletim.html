VIAS URINÁRIAS OBJETIVO — Boletim de avaliação (render determinístico)

Cada caso: feições montadas à mão → laudo objetivo (TÉCNICA / ACHADOS / IMPRESSÃO). Valide: (1) o achado INCORPORADO na frase do rim (após "apresentando"), com a sequência imagem → ecogenicidade → tamanho → localização → fenômeno acústico; (2) os mapeamentos achado↔impressão (litíase → cálices; cisto → terço; cisto complexo "de aspecto inespecífico"); (3) DRC bilateral → item único; (4) a fidelidade das frases do estilo objetivo.

1. Normal (silêncio → normalidade)

Feições: Rins de dimensões normais, sem achados focais; bexiga normal.
Esperado (clínico): IMPRESSÃO: rins/ureteres/bexiga normais
