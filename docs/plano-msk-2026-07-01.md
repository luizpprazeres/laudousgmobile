## 1) O que aconteceu (evidência do teste)

**Ditado (entrada):**
> "Joelho direito com Tendinopatia da pata de ganso, pé esquerdo com fasciite plantar."

**Saída em prod (trechos do corpo):**
```
OS SEGUINTES ASPECTOS FORAM OBSERVADOS:
Tendão quadricipital de espessura, continuidade e ecotextura preservadas.
Tendão patelar de espessura, continuidade e ecotextura preservadas.
Tendinopatia da pata de ganso          ← DIAGNÓSTICO no corpo (deveria ser morfologia)
Ausência de derrame articular significativo.
...
```
```
OS SEGUINTES ASPECTOS FORAM OBSERVADOS:
Fasciite plantar                        ← DIAGNÓSTICO no corpo
Estruturas tendíneas avaliadas com espessura, continuidade e ecotextura preservadas.
...
```

**O que está CERTO** (não regride): cobertura de todas as estruturas do roteiro,
posição correta do achado no roteiro, frases canônicas de normalidade, conclusão
com lateralidade, formato/espaçamento. Isso já é garantido (REGRA #1 de cobertura +
`sectionSpacingGuard`; e o renderer V2 quando ativado).

**O que está ERRADO:** a linha do achado no CORPO é o **diagnóstico** ("Tendinopatia
da pata de ganso"), não uma **descrição ecográfica** ("Tendões da pata de ganso com
espessamento e perda do padrão fibrilar junto à inserção tibial"). Viola a Doutrina
MSK regra #4 (corpo = morfologia; conclusão = diagnóstico) no nível do **conteúdo**.

## 2) Causa-raiz (comprovada, independe de writer vs renderer)

Rodei o **renderer determinístico V2** no mesmo input (extração LLM + montagem em
código). Resultado da extração:

```json
{ "estrutura": "pata_de_ganso",
  "descricao_corpo": "Tendinopatia da pata de ganso",       ← LLM ecoou o diagnóstico
  "diagnostico_conclusao": "Tendinopatia da pata de ganso à direita." }
```

→ O corpo saiu **byte-idêntico** ao de prod. Ou seja: **ativar o renderer V2 NÃO
resolve sozinho** este caso. A raiz é que **o médico ditou só o diagnóstico, sem
morfologia** — e nem o writer nem o renderer têm de onde tirar a descrição do corpo,
então ecoam o diagnóstico.

Esse padrão de ditado (**só-diagnóstico**) é **muito comum** em MSK ("tendinopatia
da pata de ganso", "fasciite plantar", "bursite", "epicondilite") — daí o impacto
em volume.

> (flag de ativação) — logo prod usa o **caminho writer** com a REGRA #1 de cobertura.

## 3) Solução — Biblioteca de morfologia canônica MSK (P0)

**Ideia:** o CÓDIGO passa a dono da **descrição morfológica do corpo** para os achados
comuns. Quando o médico dita só o diagnóstico, o renderer injeta a morfologia canônica
daquele achado. Quando o médico DESCREVE a morfologia, preserva a redação dele.

### 3.1 Schema de extração (mudança)
Trocar o par atual por três campos por alteração:
- `achado_tipo`: **slug normalizado** de um enum de achados MSK conhecidos
  (`tendinopatia_pata_de_ganso`, `fasciite_plantar`, `bursite_subacromial`, …).
- `descricao_livre` *(opcional)*: SÓ quando o médico realmente descreveu a morfologia
  (medidas, características). `null` no ditado só-diagnóstico.
- `diagnostico_conclusao`: como hoje (conclusão).

### 3.2 Regra do renderer (`renderLaudo`)
```
corpo_da_alteracao =
    descricao_livre                       // médico descreveu → preserva
 ?? ACHADOS_CANONICOS[achado_tipo]        // só-diagnóstico → morfologia canônica
 ?? fallbackFlag(achado)                  // desconhecido → mantém + telemetria
```
Isso mata o eco: `descricao_livre` nunca é o diagnóstico (o prompt garante), e o
fallback canônico é uma descrição ecográfica de verdade.

- Instruir: "Se o médico ditar SÓ o diagnóstico (sem morfologia), deixe

- Few-shots de ditado só-diagnóstico → `achado_tipo` + `descricao_livre:null`.
- Manter regras existentes (nomenclatura polias A1/A2, quirodáctilo, nunca "artrose").

- **Sinônimos → `achado_tipo`**: "pata anserina"/"pata de ganso"/"tendão conjunto";
  "esporão do calcâneo"/"fasciopatia plantar"; etc.
- **Estrutura fora do roteiro**: entra como linha extra no corpo (já suportado) — mas

- **Sanity MSK**: nenhum item de conclusão vazio; nunca diagnóstico literal no corpo
  (guard: alertar se a linha do corpo == `diagnostico_conclusao`).

## 6) Validação
- **Goldens determinísticos** (sem LLM) da biblioteca: para cada `achado_tipo`, corpo
  canônico + conclusão corretos, na posição do roteiro, cobrindo normais.
- **Goldens de extração (LLM)** dos ditados só-diagnóstico do caso real: pata de ganso,
  fasciite plantar (e mais 5–8 comuns).
- **Adversarial**: ditado COM morfologia → `descricao_livre` preservada (não sobrescrita
  pela canônica); ditado misto (um achado descrito + um só-diagnóstico).
- Revisão dex1 (codex) antes de ativar.

- **Não inventar medida**: canônico é measurement-free (lição TIREOIDE "____ x ____").
