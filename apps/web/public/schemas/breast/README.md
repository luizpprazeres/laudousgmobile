# Base anatômica mamária v3

Base bilateral original gerada com `gpt-image-2` pela OpenAI Image API. A imagem contém somente os contornos anatômicos e detalhes monocromáticos discretos. Aréolas, mamilos, quadrantes, relógio, numeração e achados são desenhados pela camada SVG interativa da web.

A composição usou as bases já aprovadas da tireoide e da posição fetal como referências de estilo. O primeiro resultado foi descartado por parecer um corte anatômico; o segundo, por ter proporção piriforme excessiva. A versão publicada encurta e lateraliza os prolongamentos axilares, amplia o corpo do mapa e mantém o centro livre para os marcadores. O arquivo web foi recortado para a proporção do painel sem alterar horizontalmente a anatomia.
