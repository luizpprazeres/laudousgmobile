# Category linearts

Fonte canônica dos 14 linearts acrescentados ao seletor de exames em 30/09/2026.
Web e Android recebem cópias byte a byte destes PNGs; o iOS usa os mesmos arquivos
em `Assets.xcassets`. As imagens são apenas navegação e nunca participam do laudo,
de cálculos ou de decisões clínicas.

Os originais foram gerados em modo create com GPT Image e normalizados para PNG
RGBA 256 × 256, traço `#374151` e fundo transparente.
