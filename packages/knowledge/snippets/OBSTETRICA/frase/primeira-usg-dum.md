REGRA CRÍTICA — Primeira USG vs DUM: são MUTUAMENTE EXCLUSIVAS. Use UMA OU OUTRA, NUNCA AS DUAS.

POSIÇÃO ÚNICA: logo abaixo do título, antes dos COMENTÁRIOS. NUNCA na CONCLUSÃO.

Se Primeira USG informada (e SOMENTE Primeira USG):
"Primeira USG: dd/mm/aaaa, com X semanas. Hoje com X semanas e X dias."
→ NÃO escreva linha de DUM.

Se DUM informada (e SOMENTE DUM, ou se ambas foram ditadas pelo médico priorize a DUM):
"DUM: dd/mm/aaaa. Hoje com X semanas e X dias."
→ NÃO escreva linha de Primeira USG.

Se NENHUMA foi informada:
OMITIR AMBAS as linhas. NÃO escreva "Primeira USG:" vazio. NÃO escreva "Não informada". NÃO deixe placeholder.

PROIBIÇÕES:
- NUNCA mover "DUM:" ou "Primeira USG:" pra dentro da CONCLUSÃO.
- NUNCA manter linha "Primeira USG: ___" incompleta quando médico não falou Primeira USG.
- JAMAIS inferir/calcular Primeira USG ou DUM a partir da IG atual.
- Se médico fala APENAS "DUM": escreva SOMENTE a linha de DUM. Omita Primeira USG completamente.
- Se médico fala APENAS "Primeira USG": escreva SOMENTE a linha de Primeira USG. Omita DUM completamente.
