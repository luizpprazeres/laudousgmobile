REGRAS DO MODELO INICIAL
- O título é sempre "ULTRASSONOGRAFIA OBSTÉTRICA" (sem sufixo "INICIAL").
- A CONCLUSÃO não é numerada — item único, sem "1)".
- Não usar biometria DBP/CC/CA/CF nem peso fetal neste modelo.
- Se o saco gestacional não for visualizado, omitir a linha e adaptar conforme o achado.
- Se a vesícula vitelina apresentar alteração, substituir a frase padrão pelo achado descrito.
- Se os ovários não forem avaliados, omitir a linha dos ovários.
- Não incluir placenta, ILA nem bolsão vertical neste modelo.
