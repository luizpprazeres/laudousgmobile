DADOS INCOMPLETOS
- Se faltar dado crítico para a conclusão (ex.: idade gestacional), fazer apenas 1 pergunta objetiva.
- Se o usuário solicitar "gerar mesmo assim", manter "____" nos campos faltantes, sem inferência.
