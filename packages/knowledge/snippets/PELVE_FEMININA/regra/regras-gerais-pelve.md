REGRAS ESPECÍFICAS DA PELVE
1. Usar sempre ponto decimal (ex.: 0.6 cm, 14.0 cm³).
2. Volumes dos ovários aparecem apenas na CONCLUSÃO, entre parênteses.
3. Volume uterino:
- cálculo: L x AP x T x 0.523 (cm³)
- classificar como normal, salvo instrução explícita em contrário
4. Ovários na conclusão:
- se ambos normais: usar item único
- se alteração unilateral: separar em dois itens, um para o ovário alterado e outro para o contralateral normal
- se um ovário não for visualizado, descrever isso separadamente na conclusão
- se ambos não forem visualizados, descrever isso separadamente na conclusão
5. Doppler, líquido livre, cistos de Naboth e observações adicionais: incluir somente se informados.
6. A numeração da CONCLUSÃO deve permanecer contínua e sem saltos, mesmo quando algum item for omitido.
7. Miométrio, ovários, DIU, istmocele e achados acessórios devem ser descritos no corpo apenas no local anatômico correspondente.
8. Não usar frases de normalidade do endométrio no modelo de abortamento/produtos retidos.
9. No modelo transabdominal isolado, se a avaliação do endométrio for limitada, usar a observação própria da técnica.
10. A tabela de referência etária, quando solicitada, deve manter exatamente os mesmos valores e conteúdo, com melhor alinhamento visual.
11. Volumes (uterino, ovariano): usar SEMPRE o valor informado pelo usuário, sem recalcular. Calcular apenas se o usuário pedir explicitamente. Se dois valores diferentes forem fornecidos para o mesmo órgão, usar o último mencionado.
12. Dados contraditórios: se os achados contiverem informações mutuamente excludentes para o mesmo órgão (ex: medidas de ovário + "não visualizado"), usar a informação mais conclusiva (prioridade: "não visualizado" > medidas) e adicionar entre colchetes ao final do item correspondente: [Nota: achados contraditórios nos achados — interpretado como {escolha}.]
